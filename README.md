# 暗棋

單一網頁檔的暗棋遊戲。用瀏覽器（電腦或手機都可以）打開 `暗棋.html` 就能玩，不用安裝、不用網路。

## 功能

- **一人對電腦**：分成簡單、普通、困難三種難度，可以選擇自己先下、電腦先下，或是隨機決定
- **兩人輪流**：兩個人用同一台裝置輪流下
- 悔棋（對電腦時，會一次退回到你上一步之前）、連吃時可以選擇停止
- 翻棋有動畫、合成音效（可以關掉）、會顯示被吃掉的棋子和「連續未吃子」步數

## 規則

- 棋盤 4 × 8 格，32 顆棋子全部蓋著、隨機擺放。每回合只能做一件事：翻開一顆棋，或走動一顆自己的棋
- 第一個翻棋的人，翻到什麼顏色就是那一方
- 大小順序：帥將 ＞ 仕士 ＞ 相象 ＞ 俥車 ＞ 傌馬 ＞ 炮包 ＞ 兵卒。大吃小、同級可以互吃；**兵卒可以吃帥將，帥將不能吃兵卒**
- 只能吃已經翻開的棋
- **俥車**：直線走多格，中間不能有棋子擋著；可以直接衝過去吃路上碰到的第一顆對方棋（大小規則照舊）
- **炮包**：平常走一格；吃子時要隔一顆棋（蓋著的也算）跳過去，可以吃任何棋
- **炮包連吃**：吃完一顆後，如果同一方向還能再跳吃，可以選擇繼續或停止；不能轉彎換方向
- 勝負：把對方的棋子吃光就贏；輪到某一方卻完全沒棋可走（也沒棋可翻），這一方就輸
- 和局：雙方合計連續 50 步沒有吃子

## 電腦怎麼下棋

- 電腦**不會偷看蓋著的棋**：程式只把「看得到的盤面」和「還沒翻出來的棋有哪些」交給電腦，底牌位置完全不給（有自動測試驗證）
- 翻棋的決定是用機率計算：依照還沒翻出來的棋，算出翻到每一種棋的機會，再加權平均
- 難度差別：
  - 簡單：只看一步，偶爾會亂走
  - 普通：往後想 3 步
  - 困難：每步最多想 1.8 秒，能想多深就想多深
- 電腦在背景運算，思考時畫面不會卡住。如果瀏覽器不支援背景運算，畫面上會出現提醒，並改用主畫面計算

## 已知限制

- 悔棋可以退回翻棋前的狀態，但底牌不會重新洗牌，所以悔棋等於可以先偷看一顆棋
- 困難模式在一般玩家面前有挑戰性，但沒有到職業高手的程度

## 專案結構

```
暗棋.html             遊戲本體（規則、電腦 AI、畫面全部在這一個檔案）
tests/load-engine.js  從 暗棋.html 取出規則引擎給測試用
tests/engine.test.js  規則與電腦 AI 的自動測試
tests/selfplay.js     電腦各難度互打，檢查強弱是否合理
```

規則只寫在 `暗棋.html` 的 `<script id="engine">` 區塊這一個地方。遊戲畫面、背景運算、自動測試用的都是同一份，不會出現兩份規則對不上的情況。

## 維護注意事項

- 修改規則或電腦 AI 之後，先跑測試（需要先安裝 Node.js）：

  ```
  node tests/engine.test.js
  node tests/selfplay.js 10 0.3
  ```

  `selfplay.js` 的兩個參數分別是「每組下幾局」和「困難每一步想幾秒」。困難每一步縮短成 0.3 秒是為了讓測試跑快一點，實際遊戲裡是 1.8 秒。
- 電腦的難度設定在 `LEVELS`，棋子價值在 `VALUE`，都在 `<script id="engine">` 區塊裡
