# 暗棋 UI 改版 · 設計 spec（三個方向共用的輸入）

## 專案是什麼
既有的暗棋網頁遊戲（單一 `暗棋.html`）。規則與電腦 AI 不動，整體 UI 重新設計。

## 受眾與場景
- 一般玩家，手機直向與電腦大螢幕一樣重要
- 一人對電腦（簡單／普通／困難）或兩人同一台輪流
- 使用者偏好：手遊感（2026-10-31 回答「手遊感、沒有偏好」）

## 必須呈現的內容（三版同內容）
- 開局選單：對戰方式、電腦難度、誰先開始、開始遊戲
- 對局畫面：4×8 棋盤、雙方玩家區（名稱、顏色、是否輪到、已吃掉的棋）、狀態提示、連續未吃子 x/50、悔棋／停止連吃／重新開始／回選單
- 結束畫面：勝／負／和與原因
- 規則說明
- **平面／立體切換**：立體為真 3D（Three.js），西洋棋造型棋子，棋子上印中文字；蓋著的棋用罩杯蓋住，翻棋時掀開；可拖曳旋轉視角
- **音效**：強化程式合成（不用音檔），事件更豐富（選棋、翻棋、走棋、吃子、連吃、吃到大子、無效點擊、快和局警示、勝負和），附音量調整

## 棋子造型對應（立體模式）
帥將＝國王、仕士＝皇后、相象＝主教、俥車＝城堡、傌馬＝騎士、兵卒＝士兵、炮包＝自訂砲台造型

## 輸出格式與尺寸（三版統一）
- 可實際遊玩的單頁 HTML 原型，接上真正的規則引擎與電腦
- 截圖兩種：桌機 1440×900、手機 390×844

## 已知約束
- 不需要網路：Three.js 用本機檔案（vendor/three.global.js）
- 可讀性：正文 ≥14px、標籤 ≥12px、對比 ≥4.5:1
- 規則唯一來源仍是 `暗棋.html` 的 engine 區塊（原型用 tools 抽出的副本）
